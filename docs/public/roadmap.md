# Roadmap

This page lists what each Product offers now, what comes next and what comes later. It has no dates. Items under Next and Later are announced: they do not exist yet, and their order and content can change.

Everything else in this documentation describes only what the current version does.

## CLI

The command line, `rulelink`.

### Now

- Set up a project with [`rulelink init`](cli/init.md).
- Create, review, search and retire Rules with the [`rulelink rules`](cli/README.md) commands.
- Keep the Source in its canonical form with [`rulelink rules format`](cli/rules-format.md).
- List the code that cites a Rule with [`rulelink where`](cli/where.md).
- Report Findings for the whole project with [`rulelink check`](cli/check.md): an unknown Rule in code, an obsolete Rule still cited, a validated Rule with no code.

### Next (announced)

- Help your AI agent read, annotate and propose Rules, with a person approving each one.
- Propose Rules from an external file.
- Install with a package manager.

### Later (announced)

- Import Rules from tools such as Jira, CSV files and GitHub issues.
- Publish Rules as a readable page, for example in Confluence.
- Install from more places.
- More ways to read Findings, such as in CI tools.

## IDE Support

### Now

Nothing yet.

### Next (announced)

- An extension for VS Code that shows the Rule behind an Annotation.

### Later (announced)

- An extension for IntelliJ.
