# Crates

Rulelink is a set of Rust crates. The seven below are reusable: you can depend on them from your own tools. The application crates (`rulelink-cli`, `rulelink-app`, `rulelink-publish`, `rulelink-lsp`) are not documented here.

The reference is generated by `rustdoc` at each release, with warnings denied. It is served with the site under `/api/`.

| Crate                  | Purpose                                                           | Reference                               | Changelog                         |
| ---------------------- | ----------------------------------------------------------------- | --------------------------------------- | --------------------------------- |
| `rulelink-model`       | Rules, Identifiers, statuses and links.                           | [reference](/api/rulelink_model/)       | `crates/model/CHANGELOG.md`       |
| `rulelink-registry`    | Rule lifecycle, Identifiers and queries.                          | [reference](/api/rulelink_registry/)    | `crates/registry/CHANGELOG.md`    |
| `rulelink-link`        | The Annotation grammar and the index of where each Rule is cited. | [reference](/api/rulelink_link/)        | `crates/link/CHANGELOG.md`        |
| `rulelink-check`       | Consistency checks between Rules and code.                        | [reference](/api/rulelink_check/)       | `crates/check/CHANGELOG.md`       |
| `rulelink-import`      | Import of Rules from files and external sources.                  | [reference](/api/rulelink_import/)      | `crates/import/CHANGELOG.md`      |
| `rulelink-config`      | Project discovery and `rulelink.toml`.                            | [reference](/api/rulelink_config/)      | `crates/config/CHANGELOG.md`      |
| `rulelink-adapter-sdk` | Adapter contract: traits, protocol types and conformance kit.     | [reference](/api/rulelink_adapter_sdk/) | `crates/adapter-sdk/CHANGELOG.md` |

Each crate has its own changelog in its folder in the repository. The release tool creates the file at the first release of the crate, so none exists yet.

The `/api/` links work on the published site only. In a local `astro dev` or on GitHub they do not resolve. To see them locally, run `moon run site:build :api-docs :site-bundle` and open `target/site`.
